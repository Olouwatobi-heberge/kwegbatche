# Données

Ce dossier accueille les métadonnées, listes de fichiers et scripts d'accès aux corpus. **Ne pas committer les audios lourds**, ni les archives tar, ni les checkpoints.

## Corpus à télécharger à part

- **Fon** : [JaimeMaLangue/JML-fon-speech-v1](https://huggingface.co/datasets/JaimeMaLangue/JML-fon-speech-v1) (CC-BY-SA-4.0). Audio WAV mono 16 kHz. Respecter l'attribution et le share-alike.
- **Yoruba** : Common Voice Yoruba (CC0). Aucun jeu yoruba public n'est encore listé sous l'organisation Hugging Face JaimeMaLangue.

Placer les enregistrements locaux éventuellement collectés par l'équipe sous `data/audio/` (déjà ignoré par Git).
